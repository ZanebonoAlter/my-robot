# 语义板块文章匹配严重跨域误判

## 症状

选中"中东冲突事件"板块（ID 2191），相关文章列表中出现了完全不相关的文章，例如 "mini-cc：一个轻量级 AI 编程助手的诞生"。

## 诊断

该文章有 5 个 AI 编程标签，经过 topic_tag_board_labels 全部以 hit_rate 理由匹配到了中东板块（score: 0.75~1.0）。

直接查库确认余弦相似度：

| 辅助标签 A | 辅助标签 B | 余弦相似度 |
|-----------|-----------|-----------|
| Claude Code | 伊朗 | 0.6503 |
| Anthropic | 伊朗 | 0.6649 |
| Anthropic | 以色列 | 0.6532 |
| 开源 | 中东 | 0.6676 |
| OpenAI | 以色列 | 0.6512 |

全部超过默认 SimThreshold=0.6。使用中的 embedding 模型 Qwen3-Embedding:4b 区分度不足。

## 临时缓解

当前默认 SimThreshold 已从 0.6 提升至 0.72（在 semantic_board_matching.go 的 loadConfig 中）。

## 根治方向

1. **替换 embedding 模型** — 实测 bge-m3 / gte-Qwen2 等更大参数模型，验证跨域相似度能否降到 0.3 以下
2. **匹配算法增加领域隔离** — 给板块打 domain 标签，匹配时规避跨域匹配
3. **匹配过程可视化** — 在 UI 中展示每个标签-板块匹配的相似度明细，便于调试

## 关联案例：聚类分组与持久话题锚定的「叙事方向」误判（2026-06-26）

> 与上面的 board 匹配跨域误判**同源（语义/embedding 误判）但不同层**：上面是 tag→board 的**匹配层**（`topic_tag_board_labels`）；本节是 board 内部「聚类分组 → 持久话题锚定」**层**。两层的 embedding 基础设施与校验机制完全不同，但都会让「语义上不相关的内容混进来」。

### 症状

board 1974「中东地缘政治与美伊关系」2026-06-26 日报中，事件 tag **30582「伊朗否认将用解冻资产购买美国农产品」**（美伊经贸叙事）被错误归入持久话题 **「以黎冲突升级：停火破裂与军事打击」(topic 2)**。

更讽刺的是：它的同叙事兄弟 **30589「特朗普宣布用伊朗资金购买美国农产品」**（同是「解冻资产买农产品」叙事）被 LLM 分到了**另一组**「霍尔木兹海峡」，两个都锚错——证明这是系统性缺陷，不是个案。

### 诊断：距离矩阵（cosine distance，`<=>` 口径，阈值 `MatchThreshold=0.30`）

| tag | topic 1 美伊协议 | topic 2 以黎冲突 | topic 116 资产解冻 | 实际锚定 |
|---|---|---|---|---|
| 30444 以黎谈判（同组·真以黎） | 0.3435 | **0.2474** ✅ | 0.2342 | topic 2 ✅ |
| 30918 以黎会谈（同组·真以黎） | 0.3236 | **0.2516** ✅ | 0.2414 | topic 2 ✅ |
| **30582 解冻资产否认（异类）** | 0.2977 | **0.3340 ❌ 超阈值** | **0.2348**（真实归属最近） | topic 2 ❌ |
| 30589 资金买农产品（解冻兄弟·对照） | **0.2799** | 0.3874 ❌ | 0.3040 | （霍尔木兹组，也错） |

关键结论：

- **30582 自己的 embedding 就否决了「以黎」归属**：它到 topic 2 的距离 **0.3340 > 阈值 0.30**，而同组真以黎新闻是 0.2474/0.2516。真成员 ~0.25、异类 0.334，中间有干净的分离带（0.25~0.33）。
- **30582 真实叙事归属清晰**：到 topic 116（资产解冻）最近 = 0.2348，到 topic 1（美伊协议）= 0.2977，都远近于到 topic 2（0.3340）。

### 病根：双重确认作用于「组级聚合」，稀释了 tag 级异质性

`planTopicAssignments`（`daily_report_assignment.go:153`）的双重确认：

1. **embedding gate**：`section.embedding`（**组 label** embedding）到 topic 的距离 ≤ 阈值
2. **LLM gate**：`matched_topic_id` 指向阈值内 topic

两者**都作用于组级聚合体**。本案 section 1 的组 label「以黎冲突谈判重启与伊朗立场博弈」是 LLM 自行命名的，2/3 成员是真以黎新闻，**组 embedding 被这两条主导，把 30582 的异类方向稀释为不可见**（section→topic2 = **0.1344**，远低于阈值，`anchor_hit` 放行）。

> **本质：校验「这一坨整体像不像以黎冲突」，没有校验「坨里每一条是否都像以黎冲突」。** LLM 只要靠字面（「伊朗/中东」）把异类塞进组、并按多数派命名，section 级 gate 就会连同异类一起放行。组 label 和锚定用的是同一套字面信号，等于让 LLM「自己出题自己批卷」。

聚类层的上游缺陷（加剧因素）：`buildClusterPrompt`（`daily_report_cluster.go`）的输入只有 label + description + article_count，**不带任何质量/叙事信号**。LLM 看不见 30582 是 weighted 兜底弱匹配，只能靠字面沾边打包，还会把同叙事兄弟（30582/30589）拆散到不同组。

### 治本方向：tag 级叙事方向校验（复用现有阈值，零新参数）

在 `planTopicAssignments` 锚定成功（`anchor_hit`）后、持久化前，插一道 **tag 级一致性校验**：

```
对每个 anchor_hit 的 section：
  令 topic = 该 section 锚定到的持久话题
  对组内每个 tag，算 tag.identity_embedding → topic.embedding 的 cosine distance
  若某 tag 距离 > cfg.MatchThreshold（复用 0.30）：
      → 该 tag 叙事方向与该 topic 不一致 → 从该组剥离
      → 剥离的 tag：单独成组或并回全局最近邻组后重跑锚定
```

本案验证：30582→topic2 = 0.334 > 0.30 → 剥离；30444/30918→topic2 = 0.247/0.252 < 0.30 → 保留。精准、零误伤。

**边界（重要）**：只做「tag 与**本组锚定 topic** 的一致性校验」，**不做**「tag 全局最近邻重指派」。原因：30444（真以黎）到 topic 116（资产解冻）= 0.2342，比到 topic 2（以黎）= 0.2474 还近——说明「以黎冲突」和「资产解冻」在 embedding 空间本身就挨得近（topic 间有重叠），全局重指派会把真以黎新闻误判成资产解冻。tag 级校验只回答「这条是否属于本组锚定的那个话题」，不回答「这条全局最该属于哪个话题」。

### 与 `quality-scoring-observability` change 的关系

该 change 不治本（scope 写死「不动匹配/聚类算法」），但 `quality_breakdown` 列让用户在探究区看见色差：30582 在以黎冲突组里显示为 weighted 0.73（灰），同组 30444/30918 显示为 direct_hit 1.0（绿）——「这条凭什么混进来」由黑盒变透明。治本（tag 级叙事校验）留待后续 change。
