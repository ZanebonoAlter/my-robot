日报泳道驱动聚类

先以 PersistentTopic 泳道为骨架用 embedding 分桶，LLM 退化为弱区裁决 + 新叙事兜底　·　change: daily-report-lane-driven-clustering

痛点：当前两段式聚类，偏差双层放大

① 跑题 thread 搭便车
fit>0.28 占 14%（338/2395）。「蚂蚁投资薄荷健康」挂在「SpaceX 上市波动」section
② 万能包装标题强行打包
「开发者工具链：视频弹幕与 BFF」——两个不相关事件塞一组
③ 脑补标题
「存储芯片暴涨」tag 只有「CXL 技术」（脑补了「价格暴涨」）
④ section↔topic 错锚（事后匹配放大）
「巴林银行合并」↔「卡塔尔赠送星链」(0.300)——两个宽泛标题向量恰好落在弱区就锚上
⑤ 跨 board 重复发散　同 tag 挂多 board 各聚一遍，标题各异（最近 1 天 15 tag 跨 ≥2 board）
根因：LLM 同时承担「发现新叙事 + 归并旧框架 + 起标题」三职，事后再用两个宽泛标题做向量匹配 → 偏差双层放大。

核心方案：三层分桶，section 天生挂 topic

当天 event tag（去重 + 质量筛选）
↓
按 topic 质心最近邻分桶
↓
L1 直挂　~47%
质心 dist < 0.18
直接挂 topic · 不调 LLM
confidence = anchor_hit
L2 LLM 裁决　~51%
dist ∈ [0.18, 0.30]
top-K 候选 topic「留/换/新」三选一
keep/switch = anchor_hit
L3 新建　~1.3%
dist > 0.30 或 LLM 选「新」
起新叙事标题 · 开 candidate
confidence = auto_new
关键：section 在生成阶段就挂 topic（L1 直挂 / L2 LLM 挂 / L3 新建），消除事后 section 标题↔topic 匹配（形态④错锚的根源）。LLM 从「自由聚类全量 tag」退化为「只处理 L2+L3 子集」。

三个关键决策（数据驱动，含一个推翻）

① 质心 vs 首义

62%
质心强挂率
首义向量（首条 section 标题继承）太旧太偏。质心平均历史 section，强挂 14%→62%，<0.25 覆盖 88%。

② 双向最近邻 → 推翻

340→84
单向 vs 双向 <0.18
双向（互为最近）砍掉 75%，误杀 Kimi K3↔智谱GLM 等真强匹配。原因：topic(67) ≪ tag(718)。L1 用单向。

③ 吸尘器 topic 检测

strong=0
「中国央行新闻」
万能标题 topic 质心过宽，把出口管制/WAIC 全吸成最近邻。strong/(strong+mid)<20% 判过宽 → 挂它的 tag 降级 L2。

不做的事 + 风险

本 change 不做（留后续）

  • tag 碎片化去重（33% tag 有 <0.10 近重复邻居）
  • 跨 board 重复聚类（同 tag 多 board 各聚）
  • 历史 section 归属回刷（保持原 confidence）

风险

  • 质心继承历史 section 偏差 → 吸尘器检测兜底
  • L2 占 51%，LLM 调用量仍可观（但输入聚焦，质量提升）
  • centroid 增量更新并发 → 生成后异步重算，读旧值可接受
部署后用户可见：日报 section 不再出现「万能包装标题强行打包不相关 tag」；section↔topic 错锚大幅减少；topic 泳道跨天连续性增强。
旧数据降级：历史 section 归属不变（不回刷），仅新日报走新流程；质心首次按历史 section 离线构建一次。
