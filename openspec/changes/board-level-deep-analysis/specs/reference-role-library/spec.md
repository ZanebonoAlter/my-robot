## Purpose

全局参考角色库：存放方法论画像文档（如《内部看美国·方法论画像》——命题生成模式/论证骨架/证据纪律/反面段），在数据增强分析（版块级与单泳道）的三角色 prompt 中注入，作为分析的结构与方法论锚，替代「产出质量全靠 LLM 即兴」的现状。

## ADDED Requirements

### Requirement: 参考角色文档模型

参考角色文档 SHALL 包含：名称、markdown 内容、enabled 开关、创建/更新时间。文档 MUST 为全局库（不绑定具体版块，区别于板块数据源绑定 `board_data_sources`）；文档 SHALL 支持启停（enabled=false 时不注入）。

#### Scenario: 文档全局可用

- **WHEN** 任一板块（或泳道）发起分析且存在 enabled 的参考角色文档
- **THEN** 注入逻辑不感知板块差异——同一份文档对所有分析同等可用

#### Scenario: 停用即时生效

- **WHEN** 用户将某参考角色文档置为 enabled=false 后发起新分析
- **THEN** 该文档不注入本次及后续分析，无需重启服务

### Requirement: 参考角色 CRUD

系统 SHALL 提供参考角色文档的列表/详情/创建/更新/删除/启停接口。单用户系统，MUST NOT 引入权限体系。

#### Scenario: 手工录入首份画像

- **WHEN** 用户通过管理界面录入《内部看美国·方法论画像》并启用
- **THEN** 文档入库并在下一次分析中生效（本期内参考角色文档均为手工录入，自动生产线后置）

### Requirement: 注入时机与格式

参考角色文档 SHALL 在分析编排的 prompt 装配阶段注入三角色（解读员/探索 agent/分析员）的 system prompt，注入形态为方法论指引（怎么立论/怎么组织论证/证据纪律），MUST NOT 注入为「待复述的内容素材」——参考角色提供的是切角与结构，不是事实来源；分析的事实 MUST 仍来自泳道素材与 web 证据。

#### Scenario: 注入的是方法而非事实

- **WHEN** 含参考角色文档的分析产出报告
- **THEN** 报告中的事实性论据均来自泳道引用或 web 证据，参考角色文档不成为证据 source_type（证据链中不出现「参考角色」类型的依据）

#### Scenario: 无文档时行为不变

- **WHEN** 参考角色库为空（或全部停用）时发起分析
- **THEN** 分析编排行为与注入前完全一致（零文档=零影响，不报错不降级提示）

### Requirement: 注入用量控制

多份 enabled 文档同时存在时，注入总量 SHALL 受上限控制（超限时按更新时间新者优先截断并在调用日志留痕），防 prompt 膨胀失控。

#### Scenario: 超限截断可追溯

- **WHEN** enabled 文档总量超出注入上限
- **THEN** 按规则截断注入，且本次注入了哪些/截断了哪些可经调用日志追溯
