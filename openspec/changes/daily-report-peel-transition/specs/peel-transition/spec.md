## ADDED Requirements

### Requirement: 方向化翻页转场

系统提供可复用的翻页转场，支持按切换语义选择方向：`horizontal`（横向，用于同级内容翻页，如日期）与 `vertical`（纵向，用于跨类切换，如版块）。两种方向各自独立编排进入与离开动画，方向可由调用方在切换前指定。

#### Scenario: 切换日期触发横向翻页

- **WHEN** 用户在日报视图切换到另一天的日报
- **THEN** 旧日报内容向某一横向方向卷起消失，新日报内容从相反横向方向铺开出现

#### Scenario: 切换版块触发纵向翻页

- **WHEN** 用户切换到另一个版块的日报
- **THEN** 旧内容向某一纵向方向卷起消失，新内容从相反纵向方向铺开出现

#### Scenario: 调用方显式指定方向

- **WHEN** 调用方在触发内容切换前将方向设为 `horizontal` 或 `vertical`
- **THEN** 本次转场按所设方向执行，且不影响后续切换的方向选择

### Requirement: 仅切换瞬间触发

转场只在内容切换的瞬间发生。切换完成后，不持续运行任何覆盖型或跟随型特效，确保阅读体验不被干扰。

#### Scenario: 转场完成后无残留特效

- **WHEN** 一次切换转场结束
- **THEN** 页面呈现为静态可读内容，其上无持续运行的动画层

### Requirement: 全浏览器兼容与优雅降级

转场不依赖任何实验性浏览器 API（如 html-in-canvas）。在主流浏览器的常规安装下即可工作；当浏览器对所用 CSS（clip-path / 3D transform）支持不全时，降级为无动画的直接切换，不抛错、不影响内容可读性。

#### Scenario: 主流浏览器正常呈现

- **WHEN** 用户在主流浏览器的常规安装下切换日报
- **THEN** 转场以 transform / clip-path 正常完成翻页效果

#### Scenario: 支持不全时降级

- **WHEN** 用户浏览器对所用 CSS 支持不全
- **THEN** 内容仍正常切换并可读，不报错

### Requirement: 可复用与参数化

转场以独立 composable + 组件形式提供，与日报逻辑解耦。距离、旋转角度、时长、缓动均可通过参数配置，便于其他视图复用。

#### Scenario: 复用到其他场景

- **WHEN** 其他视图需要同类方向化翻页转场
- **THEN** 可直接复用该组件并传入 `direction` 与时序参数，无需改动日报代码
